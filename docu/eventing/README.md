# Eventing

BaSyx Go can publish AAS and Submodel changes as CloudEvents through message
brokers or a REST Event Feed. All transports are experimental and must be
enabled explicitly.

| You want to | Read |
| --- | --- |
| Publish events over MQTT 5 | [MQTT eventing](mqtt_eventing.md) |
| Publish events over AMQP | [AMQP eventing](amqp_eventing.md) |
| Publish events to Kafka | [Kafka eventing](kafka_eventing.md) |
| Enable the Event Feed or read events over HTTP | [Event Feed](event_feed.md) |
| Understand the eventing runtime | [AAS API v3.2 runtime notes](../developer/aas_v3_2_runtime.md) |
